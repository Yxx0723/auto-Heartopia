# 水域分层与碰撞层级优化

## 问题

v2 界面上，一块湖同时被两条几乎重合的轮廓夹着：水面外圈是 5px 的岸带（`shore_outer`）+ 1.5px 岸线（`shore`），而山体碰撞用 `#bb9874` 的 2px 实线压在**水面之上**。结果湖里也能看到黄褐色的碰撞线，岸线读不出边界，水面本身只有一块平色，高倍缩放下还能看到像素级台阶。

## 改法

`utils/ui/map_presentation.py`

- 新增 `water_colors()`：把调色板解析成水域四层角色色。浅水取 `water_shallow`/`water`，深水取 `water_deep` 或浅水色 ×0.72，岸外阴影取 `water_bank` 或水色 ×0.6，岸线取 `water_edge`/`shore`。v2 与 HUD 两套键名都能落到位，换主题不用改绘制逻辑。
- 新增 `WATER_LAYERS` / `WATER_WIDTHS` / `WATER_EDGE_SCALE`：岸外阴影 3px、水面 1px、小岛 0.8px，远景档再乘 0.82/0.66，缩小时细边不会糊成一团。
- 新增 `smooth_coords()`：Chaikin 圆角一次。只给深水色块用；水面外轮廓与岸线保持实测边界，不做平滑。
- `MAP_STYLE` 增加 `terrain` 角色色（v2 ≈ 原亮度的 45%），山体宽度常量 `TERRAIN_WIDTH=2`、世界碰撞盒 `COLLISION_WIDTH=1`。

`utils/ui/monitor_painter.py`

- 绘制顺序改为**先碰撞、后水面**：山体与世界碰撞盒排到 `map-rank -8`，水面在 -6/-5/-4。湖里的碰撞轮廓被水面盖住，岸线只剩水面自己那条细边。
- 深水层用次一级简并轮廓（`visible_water_layer(..., level_offset=1)`）再圆一次角，1x 下没有台阶；顶点总量从 964 降到 696。
- 桥梁仍在水面之上（-1），围栏/护栏仍在符号层，不参与这次重排。

`utils/ui/map_draw_cache.py`

- `visible_water_layer()` 增加 `level_offset`，缓存键改为 `(kind, offset)`。
- `finish()` 的 `tag_raise` 顺序扩到 `-8…-2`，保证层级真的按新顺序生效。

## 核对

- 对比图 `outputs/水域与碰撞显示-20261022.png`：左为 v2 真机截图原始像素，中/右按新规则重画同一视角同一比例（6.2px/单位）。样式常量与宽度全部取自 `map_presentation`，所以右图就是程序会画出来的东西。
- 逐项比对：湖内碰撞线消失（被水面盖住）、岸带 5px→3px 且改为深色阴影、水面出现浅/深两层、岸线只留 1px。
- 新增回归：`test_water_roles_resolve_for_the_v2_and_hud_palettes`（两套调色板都能解析出四层角色色）、`test_deep_layer_uses_a_coarser_contour_and_rounds_only_its_own_corners`（偏移档位生效、圆角不越界）。
- `python -m pytest tests` 全绿。

## 边界

深水层是**显示样式**，来自 5px 腐蚀后的水面掩膜，不表示实测水深，也不参与寻路。碰撞仍然只是轮廓参考，不改碰撞数据。当前在跑的 exe 是 v2 配色（2026-10-22 14:09 回滚），源码工作区是 HUD 深色主题，这次改动对两套主题都成立，但打包前要先定用哪一套配色。

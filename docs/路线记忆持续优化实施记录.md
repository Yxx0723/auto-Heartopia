# 路线记忆持续优化实施记录

日期：2026-10-23。基于restore/d50087c-20261023 / 999eabf增量修改，未恢复P1/P2支撑面架构。

## 实现

- memory_corridor.py提供有序轨迹形状比较、近期中位数耗时、近期遇阻率代价和分段计时校验。比较时的重采样只用于统计归组，不保存为可行走路线。
- RoutePathMemory继续兼容route-path-memory-v1。每点最多三条实走候选，轻微坐标抖动归并到同一保留轨迹，累计成功次数；不平均坐标、不改变采集点或访问顺序。
- 保留best_seconds供旧版本读取，新择优使用最近7次有效耗时中位数及最近7个成功/遇阻结果。没有新计时的旧记录使用旧计时或原路程/估计速度。
- 有有效sample_times时按该保留实走轨迹的分段时间比例估算剩余耗时，再结合近期整体耗时和接入代价。近似轨迹归并不会伪造该保留轨迹的逐点时间；未得到可对齐计时的旧记录退化为路程比例。
- 记录活动通行耗时，包括绕行、脱困及重新校准；到点时冻结计时，采集等待及F6暂停、进食维修等暂停移动流程不计入。首次建立方向基准在本段计时之前。
- 走法被拒绝后即时降低优先级。结束时即使没有后续成功段，也尝试落盘遇阻记录；后续成功会更新近期窗口，惩罚可逐步消退。
- collection_outcome与loot_confirmed区分采集动作完成和收获确认。当前普通点位不声称确认掉落。
- 已知跳跃会丢弃当前普通行走学习段。接入候选先检查当前碰撞、水域与方向风险，再比较代价，前瞻仍保留原几何及水域约束。
- 无计时的旧式输入只清除完全重合XYZ的回环，不清除近似返回；带逐点计时的输入保留实际行走形状。
- 原子写入失败或超过原有50000点容量上限时回滚未写入统计，保留待保存失败证据；不影响采集后的按键释放。

## 边界

当前没有可靠grounded、完整支撑面网格或稳定的桥上桥下身份。XYZ连续及行走输入是观测证据，不能证明未知区域一定有连续地面，也无法排除所有未经观测的载具/游泳状态。形状归并不是两条邻近路径之间可通行的证明；实际执行仍重新检查当前已知水域、碰撞和方向风险。

没有通过未走过的跨河直线生成新几何；没有将失败变成永久硬障碍。记忆开关保持用户现有状态，没有操作真实游戏、启动F6或自动采集。

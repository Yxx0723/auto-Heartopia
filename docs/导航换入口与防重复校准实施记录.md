# 导航换入口与防重复校准实施记录

日期：2026-10-23。基于 `restore/d50087c-20261023` / `748d9fc` 及原有未提交的回放记录功能增量修改。

## 实现内容

### A：观测质量与校准预算

- 新增 `utils/core/direction_evidence.py`，区分对齐、障碍嫌疑、方向变化候选及未知。
- 单个方向偏移不构成镜头旋转事实。方向变化候选要求时间窗内多个一致样本和不同方向轴；结果仍注明没有直接观测镜头。
- 跳跃、恢复过渡、高度变化过大、位移不足或非有限数值不参与方向学习。
- 同一区域及同一点位均有校准预算。场景刷新只清除区域观测，不会无限重置点位总预算。

### B：终止无效重复，明确部分完成

- 正常对齐位移不再持续旋转可信方向基准；方向异常先释放按键，记录不确定性，再有限次数核对。
- 校准预算用尽时跳过该点并继续余下点位。当前轮有跳过则报告 `cycle_partial`，整次结束报告 `partial`。
- 跳过不执行采集、不保存该段为成功走法，不计作整轮完成；历史摘要保留 `skipped_count`。
- 当前实现不自动追加补采轮次。用户设置的后续循环仍正常执行，各轮未完成的点位流程保留记录。

### C：方向性临时风险与通道选择

- 新增 `utils/core/approach_risk.py`。卡住记录成为方向性短时代价，不再由 `LocalNavigator.blocked()` 生成临时圆墙。
- 记录包括起点、尝试方向、移动方式、来源、有效期、独立尝试标识及局部几何签名。没有可靠支撑面身份时，`support_ref` 明确为未知。
- 反方向、不同移动方式及不同高度观测范围不直接复用失败代价；反向成功不会删除正向失败。
- 风险数量有上限，过期、场景变化和相关局部几何变化会失效。远处无关几何变化不额外全量重建风险目录。
- 当前A*使用原有几何检查寻找局部路径分支，并用风险代价选择不同接近走廊；保留当前路径形成稳定接近意图。
- 未新增绕目标均匀撒点、独立桥梁入口表或第二套支撑面身份系统；道路参考线没有升级成通行证明。

### D：调用链一致性

| 入口 | 硬障碍检查 | 临时方向风险 |
|---|---|---|
| A*相邻边 | 原 `ObstacleMap.clear()` | `travel_cost()`计入方向代价 |
| 初始直连 | 原几何检查 | 有风险时转入搜索 |
| 最终短连接 | 原几何检查 | 纳入目标候选总成本，不提前接上高风险末段 |
| 路径简化 | 原几何检查 | 捷径成本不得高于原走廊 |
| 导航前瞻 | 原几何检查 | 对照当前路径前缀成本 |
| WASD量化转向 | 检查真实量化方向 | 优先低风险的有效方向 |
| 记忆路径复用 | 重新检查当前几何 | 不因旧走法直接绕过新风险 |
| 旧路径缓存 | 重新检查几何 | 风险版本、有效期和场景变化触发重评估 |
| 大跳恢复 | 保留水域、山壁保护 | 不把跳跃位移当普通行走成功 |

当前回退基线采用A*，本次未引入或重写Theta*。搜索、路径前瞻和记忆复用均继续使用原有真实障碍约束。

## 默认保护参数

以下均为工程保护/观测参数，不是已校准的游戏能力：

- 同一区域最多3次校准尝试；每点每轮最多6次校准尝试。
- 每点每轮最多6次接近恢复尝试；持续场景缺失不会作为撞墙失败累计。
- 原UI的“每轮脱困次数”设置保留；新增6次是跨恢复轮次的点位级预算，两者不是同一个计数。
- 最多32条活动方向风险，有效期复用原配置20秒。
- 风险影响半径1.25游戏单位、高度观测容差0.75游戏单位；它们不是角色碰撞半径、楼层划分或真实支撑面身份。
- 其余观测时间窗、角度一致性、代价权重及同向成功消减条件集中在 `thresholds.py`，并由参数登记测试覆盖。

## 能力边界与实现调整

1. 当前数据仍缺可靠grounded标志、完整地面网格及稳定支撑面身份；高度观测容差只限制临时风险，不用于证明坡道可走或两个平台相连。
2. 控制器能有限尝试不同接近走廊，不能保证在缺失墙体或缺失地面数据时找到真实通道。
3. 方向变化候选并非镜头遥测。原地校准无法建立可信方向时，允许本点结束并保留未完成结果。
4. 没有可靠场景上下文的快照无法证明跨场景同一性；断开、过期及可观测到的上下文变化会清理风险，未知情况仅保留短时代价。
5. 现有走法记忆的启用状态没有被改动。新逻辑不替用户勾选该功能，也不修改原采集点和访问顺序。
6. 所有验证为离线模拟和打包回归，不等于稀有木材第8点已在游戏中走通。实机回放及采集需要另行确认，本次不自动启动。

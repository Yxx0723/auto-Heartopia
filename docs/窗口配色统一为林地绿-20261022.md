# 窗口配色统一为林地绿

完成时间：2026-10-22T16:47+08:00。承接 `docs/水域分层与碰撞层级-20261022.md` 末尾留的待决项——「打包前要先定用哪一套配色」。

## 问题

窗口 chrome 是深空青（`ui_tokens.COLORS`：`#04070c` 底 + `#00e5ff` 霓虹青），地图是 v2 林地绿（`map_presentation.MAP_STYLE`：`#17251f` 森林底 + 橄榄网格 + 暖褐山体），两种色温并置。另外 `green` 这个令牌的值其实是 `#00e5ff` 青色，命名与取值不符。

还有一层容易踩的：桌面快捷方式 `心动小镇坐标观测台.lnk` 指向 `outputs/心动小镇坐标监测器-窗口版.exe`，**改源码不重新打包部署，看到的还是旧配色**。

## 改法

只动 `utils/ui/ui_tokens.py` 的 `COLORS`，22 个必需键一个没增删（`test_ui_tokens.REQUIRED_KEYS` 全部保留），绘制代码零改动。

| 角色 | 旧（深空青） | 新（林地绿） |
| --- | --- | --- |
| bg / card / card_hi | `#04070c` / `#070d16` / `#0c1724` | `#050a07` / `#0a1410` / `#112019` |
| line / line_strong | `#1b4353` / `#2a6579` | `#22452f` / `#356b4c` |
| text / muted / faint | `#e6f8ff` / `#93b7c7` / `#7396a8` | `#e9f6ea` / `#9dbaa7` / `#7fa38c` |
| green（主强调） | `#00e5ff` | `#8fe36a` 苔绿 |
| blue（次要信息） | `#57c8ff` | `#6fd7b0` 薄荷 |
| amber / red / ok | `#ffb020` / `#ff3366` / `#39ff14` | `#f0c05a` / `#ff6b6b` / `#7dff9b` |
| button 三态 | `#0a1420` / `#10283a` / `#16384f` | `#0d1a13` / `#16301f` / `#1e4029` |
| primary 三态 + primary_text | `#5cf0ff` / `#00bfd6` / `#04121b` | `#a8f07d` / `#6fc94f` / `#07120a` |

`plot` 仍指向 `MAP_STYLE['ground']`，没有复制色值。`monitor_style.py` 顶部注释「深空底 + 霓虹描边」同步改成「林地底 + 苔绿描边」。

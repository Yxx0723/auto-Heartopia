# 桥段起点边距与地形高度修复

## 真实证据与修正

用户确认 14:58 这一轮桥上停止后由其手动向前移动，故后半段位置变化不算自动过桥成功。此前目标微调只覆盖起点正常的情况，不能宣称已完成实机验收。

从 26 条路径拒绝记录整理出 6 个不同停点。首次停点距细长投影约 0.325，目标距其约 0.592，均在本体之外，但都落在 0.6 安全边距内。另有多条重叠投影。

这些投影已与 `terrain_reference.py` 精确匹配，是 `mc_terrain_collider01` 的竖直地形三角面投影，不是已识别的护栏。旧数据仅保留投影线段和整面 min/max Y，可能把三角面的高度范围挤出成矩形墙，覆盖三角面在该高度实际不存在的部分。原始 cooked 导出 SHA256 为 `8ce4bd25cbb960c8e4e14bdaebf294eda8dc8bfa58f3157d2be58845b75deb5a`。

## 实施边界

1. 仅对精确匹配原 map_id、来源、类别、原轮廓和高度的地形边使用源三角面；未匹配或被修改的记录保留旧硬阻挡。
2. 3398 条旧边中 3379 条可精确关联，19 条继续使用原模型。源数据随代码静态发布，运行时不读 OBJ、扫内存或扩展碰撞读取范围。
3. 只在引导地图构建和引导脱困中按现有身体高度模型截取源三角面，保留原厚度和实体安全距离。原场景快照、地图显示和普通采集回放不改。
4. 截取高度在现有身体区间上下各扩充原 `COORD_NAV_HEIGHT_REFRESH`，覆盖地图复用期间的所有高度；不因小幅升降漏掉新出现的面。不把角色 Y 等同脚下地面，不推断 grounded 或坡度能力。
5. 人物仅位于安全边距内时，可以沿现有 `clear(..., escape=True)` 规则退出：整个线段不得穿实体或更接近障碍，终点必须通过正常检查且无风险。当前忽略水域模式适用此退出；旧岸边策略维持原要求。人物已经在目标点时不凭空生成退出动作。
6. 对实际 WASD 的预计行程检查覆盖配置中的输入许可及 watchdog 轮询时间，不仅两个正常周期。不延长许可、TTL 或停止等待。默认速度仍是工程配置，不是已测得的游戏速度上限。
7. 不恢复 P1/P2 分支，不重写 A*/Theta*，不修改路线或点位，不自动操作游戏，不增加走法记忆。

## 缓存、来源与性能

`tools/build_terrain_sections.py` 固定校验源导出哈希、格式、顶点数和三角面数，并记录原 face ID，确定性生成 `terrain_wall_profiles.py`。每个 profile 保留原边值以防索引变化误套；不匹配即使用原碰撞体。

新三角面数据不放入 IPC 场景快照，避免扩大传输负担。冻结快照准备侧额外计算地形边 ID 与几何关联签名；引导地图比较该签名，ID 消失或互换时不得复用旧截面，脱困缓存同样失效。普通导航的原几何签名保持不变。`GuidanceNavigator._build_map` 在已有空间粗筛后构建局部高度截面；原始签名和快照时效检查保留。源数据为随 EXE 发布的静态常量，不在运行期间热替换；新进程不会复用旧程序的地图缓存。高度截面覆盖原缓存带；此外，当源面在脚下/身体/头顶之间的过滤分类改变时，即使升降小于原高度阈值，也重建导航和脱困地图。分类未变的微小高度变化仍复用地图。

## 测试与验收

修改前 7 个桥段/起点用例失败、2 个通过；另一个输入许可行程用例先复现原 0.3 距离小于配置所需 0.48。修复后新专项 37 项覆盖全部日志停点、旧源身份不匹配、不同高度、真实竖直面、未知数据、完整缓存引导线闭环及中途停止。包含许可、冻结快照与缓存身份的相关回归 296 项通过。

整段缓存线闭环使用平坦模拟地面，不是游戏实际地面数据，不证明实机过桥或角色支撑面。最终完整测试 3012 项通过、27 项预期失败、23 条现有转义警告、2 项子测试通过，205.33 秒；冻结包 721 项通过，106 个模块与候选源码一致。Pyflakes、编译和暂存差异检查通过。期间在高度分类与 ID 关联回归补齐前另执行两轮中间完整测试，分别为 3003 和 3007 项通过，均不是最终交付验收。实际 EXE 只读预检 4 批快照有效，没有人物输入。

离线局部建图基准：原始 3398 条地形边粗筛后 91 条，12 次建图旧中位数 1.42 ms、截面版 4.81 ms，最大分别 1.64/5.72 ms；不包含真实 I/O、参考模型或签名准备，也不是实机帧率测量。回放既有 206 个轨迹位置用于缓存检查，共 10 次建图，未在最初桥面高度附近反复建图；轨迹包含人工移动，不能计作自动过桥。实机必须重新核对是否无需人工干预通过原桥段，失败时停止并保留原始日志，不以人工走通替代自动成功。

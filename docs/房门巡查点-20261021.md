# 萤石、橡木房门巡查

巡查点改为当前主地图 1～12 号房的门前入口。数据来自本机只读核对的 `MainGameLevelConfig.MapFieldPointsAsset.fieldPoints`，使用 `MapFieldPointAsset.fieldNo` 和 `playerPos`，不使用房屋中心 `pos`。例如 1 号房内部 `fieldID=11`，房号不能按内部 ID 排序。

入口由当前游戏注册的配置对象读取。沿用主地图类型、运行时、配置脚本绑定和容器版本校验，完整取得 12 个唯一房号后才能用于巡查；缓存受当前地图对象和列表版本约束，不保存进程地址，不读取其他玩家私有信息。

从最近房门起步，随后按房号递增，12 号接 1 号，一轮每户一次。到入口水平 3 单位内停留 3 秒核对资源。无法找到可站立点或寻路超时则记录房号和原因，继续下一户。发现有效真实资源时立即转入接近和采集，位置记录和房门本身都不授权按 F。采集数量仍采用窗口中的“连按 F”，默认 3 次。

房门入口来自游戏配置，尚未逐户实走核对；玩家建造的围栏等可能影响可达性。12 户巡查未发现目标只表示本轮未确认资源，不能证明全图没有。

实现参考了 Nav2 的逐点任务、到点处理及失败后继续机制，当前程序使用自己的只读场景导航，没有引入 ROS 依赖。公开资料通过用户指定代理访问：

- [Nav2 waypoint follower 源码](https://github.com/ros-navigation/navigation2/blob/main/nav2_waypoint_follower/src/waypoint_follower.cpp)
- [ROS 官方 nav2_waypoint_follower 文档](https://docs.ros.org/en/humble/p/nav2_waypoint_follower/)

# 采集路线原生引导：设标验证进度

日期：2026-11-03。基于 `4ecf2a1`，本阶段为只读预检及纯函数校验基础。

## 已实现范围

- `utils/drivers/map_panel.py` 从界面服务、界面层栈定位唯一已打开的地图面板，不扫描堆中的旧面板。读取地图初始化状态、画布半尺寸、选点 XZ、缩放和比例；重复核对面板、场景、运行域和地图模块归属。
- 地图的 `_viewContext` 非空不代表正在查看其他区域。读取其 `IsCurrentRegion`，类型错误、未知或读取期间变化时拒绝该观测。
- `utils/core/map_targeting.py` 只处理外部已确认的地图投影，要求两份新鲜且不变的视图，不将越界目标夹到屏幕边缘，拒绝控件遮挡的位置。
- 设标后的确认要求两份新鲜引导数据，场景、真实追踪 ID、目标 XZ 和路径版本一致。保留原点位 XYZ；引导线终点不等于采集点到达，也不等于已采集。
- `tools/coordinate_monitor.py --check-map-target-output <文件>` 只读预检，不打开工具界面、不设标、不发送移动输入。

## 当前能力边界

**尚未接入采集回放，也未实现自动设标。** 读取到画布数据不等于已完成屏幕投影校准。

预检明确输出 `projection_verified: false` 和 `automatic_targeting_ready: false`。
`current_spot_xz` 是游戏面板保留的选点字段，没有独立时间戳；未打开新增标记窗口时，它可能是默认值或旧值，不能当作本次点击成功的依据。

世界 XZ 到屏幕位置还需要可靠的当前地图平移和实时画布尺寸。当前没有将研究用的原生内存候选偏移当作已确认布局，也没有仅凭截图比例启用点击。

## 下一步和停止条件

1. 人工在当前地图空白陆地长按，打开新增标记窗口，先不保存、不缩放、不拖动。
2. 读取本次选点和独立的实际点击位置，验证画布尺寸、平移和缩放的转换。视图变化则丢弃本轮结果。
3. 完成实际设标后，核对游戏读回的追踪 ID、目标 XZ 和完整路径，拒绝被游戏重定向到其他地点的结果。
4. 验证通过后，再实现逐采集点设标、沿原生引导接近、局部精确到点和原采集流程的衔接。

遇到地图未打开、坐标投影未确认、区域或目标不符、读取过期时，不发送下一步操作。此阶段不会启动真实回放，也不会修改保存的路线或点位。

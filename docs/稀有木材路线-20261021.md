# 稀有木材采集路线

本次在用户确认的树旁，以只读方式核对到 `CollectableTreeComponent._itemTypeID = 211`，其 `TreeComponentData.resourceId = 1339`；当前主地图的固定资源配置中共有 8 棵同类树，资源编号为 1332～1339。背包物品表中的材料名称为“珍稀木材”，编号 40004。路线在窗口里命名为“稀有木材”，与橡木、普通果树路线分开保存。

使用方式：选择“稀有木材”路线，保留自动寻路，点击“按顺序回放”，切回游戏按 F6。F6 暂停/继续，F9 停止。此次仅生成路线和更新程序，没有自动启动游戏内采集。

每棵树是一个点位，最多分 3 次按 F，每次后等待 3 秒。程序在靠近后核对当前加载的树种编号、资源编号、实体归属及剩余可采次数；已没有可采次数时不再按 F。缓存、全图定义或另一个编号的树不能单独授权采集。体力补充、手持斧镐和自动维修沿用原设置。

路线从生成时的角色位置安排访问顺序，使用现有的有限时长寻路代价估计与排序。远处的站立高度及落脚点是参考，靠近后依据实时实体和碰撞重新选择站位，不能宣称所有路段或掉落结果已经实走验证。树种配置的 `hitProduce` 有 3 组，`totalData` 为 `[3, 7200]`；程序不据此保证具体掉落数量或把冷却当成材料入包证明。

新增的 `collect_count` 点位字段保存在 JSON 中，未填写的旧路线仍按 F 一次。原路线文件不覆盖，新增路线通过 PointRoutes/PointStore 原子、独占创建；重复名称会报错保留旧文件。

重新生成（在用户确认的树旁）：

```powershell
python -m tools.build_rare_wood_route --pid <当前游戏PID> --name 稀有木材
```

实现入口：`tools/build_rare_wood_route.py`；实时实体校验：`utils/drivers/rare_tree_gather.py`；站位与采集：`utils/core/mineral_approach.py`、`utils/flows/playback_collection.py`。

前置调研均经 `127.0.0.1:7897` 代理。公开[采集物资源表](https://www.heartopia.live/zh/forageables/)将稀有木材列为郊外巨树产出，仅用作识别线索；最终树种与点位由用户现场确认和本次只读数据核对。[GitHub 上的 Heartopia Helper](https://github.com/Rayyy2/Heartopia-Helper)采用 MelonLoader，不适合本项目的外部只读方式，未引入其注入、传送或游戏内调用方案。

## 数据与实际效果

本地两湖细化导出转为 `runtime/navigation/two-lakes.json`：山壁 1797 面、水面 942 面、桥梁 4169 面，共 6908 面。范围 X=-199.239990～39.041260，Z=83.870056～321.174744，世界 XYZ、Y 向上。两处站位对应的窗口相互重叠，不代表已覆盖所有湖泊或全图。

- 原有活动实体、水域、已确认山壁和桥梁检查继续决定能否通过。
- 新山壁、桥梁源网格按当前导航高度的身体区间裁切，再投影参与绕行代价。地板和头顶之外的面不投影为整片障碍。
- 新水面仅在当前高度附近参与风险计算。视觉水面不是泳区边界，不新增整片永久禁行。
- 同类三角面沿一条边的覆盖区间取并集，按暴露长度加价，不因网格加密或重复三角面增加代价。
- 已有逻辑核对的活动桥面可在其安全宽度内减去水面风险；新桥梁源网格自身不能授予跨水权限，也不移除护栏/实体检查。
- 有限风险可能仍选择一小段暴露较少的路线；不能宣称它保证避开所有未知障碍。

高度只来自当前导航坐标，仍不是实际脚下支撑高度。不推断连续坡道、台阶能力、落地状态或完整 NavMesh。
高度场每格原生三角分割与洞标志未恢复，所以预览地面 OBJ 不进入通行白名单。活动箱体依旧以实时读取为准，不把这次导出的箱体永久固定。

## 调用链与缓存

`tools/build_navigation_reference.py` → 校验来源清单/网格 → 本地 JSON → `MemorySceneMap.__init__` 一次读取校验 → 每次快照由现有游戏指纹及主地图地形门控决定是否发布 → `ObstacleMap.reference_risks` → `risk_cost/travel_cost`。

`plan_path` 的直线快捷路径、A* 邻接边、终点短连线、贪心简化均使用原有代价入口。当前实现没有另行增加或重写 Theta*。前瞻和已启用的旧走法复用也继续检查风险；不改变记忆走法的当前启用状态。

引用版本由校验后的内容摘要生成，不接受文件自行声明的版本。引用版本改变或撤除时清空局部路径及障碍图，即使场景仍是同一个 Python 对象也会重建。局部静态风险代价缓存上限 4096 项，随障碍图销毁；该缓存只缓存对称的源几何暴露，不缓存有向移动失败证据。

文件最大 4 MiB、总顶点及面数各不超过 16000，范围/索引/有限数/来源类型均校验。读取失败、损坏、版本不符或不在核实主地图时不使用这批引用；原有实时碰撞不会因此清空。不存在逐帧读取文件或解析 OBJ。

文件在场景读取器打开时加载；替换数据后需重新连接读取器。跨游戏版本必须重新核对数据，不能仅修改 JSON 中指纹强行适配。

## 本地生成与运行

```powershell
.venv\Scripts\python.exe tools/build_navigation_reference.py <地图细化目录> runtime\navigation\two-lakes.json
```

源码运行从仓库的 `runtime/navigation/` 加载。冻结版从 EXE 同级的 `runtime/navigation/` 加载，不依赖工作目录。仅复制 EXE 会缺失这批可选引用，因此交付目录及 ZIP 同时携带此文件。

这些提取的游戏几何只保存在本地缓存和本地交付包中，不提交公开 Git 仓库。公开代码包含读取器、转换工具、测试与本说明。用户路线 JSON、点位和实时轨迹未改动。当前旧窗口不由本次任务替换或启动回放。

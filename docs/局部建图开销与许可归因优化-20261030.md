# 局部建图开销与许可归因优化

## 依据与范围

前一轮实机完成跟随，但仍存在建图和许可到期造成的输入间隔。
本轮离线 CPU 剖析使用约 4200 个合成碰撞体与现有 6908 面参考数据，
发现远处碰撞体在局部排除前仍进入几何键/桥面候选计算，参考三角面也先裁剪后排除。
剖析是离线构造，不宣称已测到相同的实机场景构成。

本轮不延长 0.15 秒输入许可或碰撞/引导有效期，不改目的地、路线、点位、
到达条件和已确认碰撞约束，不启用新的持久走法记忆。

## 局部碰撞体提前筛选

`local_collision_scene()` 在指导导航建图前按完整多边形的 XZ 包围盒筛选。
范围包含原搜索半径、原导航腿长度以及不小于碰撞边距和桥面观测范围的余量。
只有完全分离的包围盒被排除；巨大跨区物体、细平面段及边界相交体保留。
无法解析的数据仍交给原验证路径，不把异常当空地。

派生局部场景不修改原快照。原完整快照仍用于场景/几何变化检查及有效期，
地图仅声明原局部索引范围；搜索半径扩大时重新选择，未使用跨快照局部缓存。
桥面识别、水域、山壁及原精确连接检查继续执行。
诊断记录建图前后的碰撞体数量，便于核实实机收益。

## 参考三角面的提前排除

共享的 `ReferenceRisks` 在高度裁剪与求凸轮廓前，先做保守 XZ 包围盒排除。
裁剪不能超出原三角形；退化投影的扩展每轴不超过 sqrt(2) 倍现有角色边距，
提前筛选采用 2 倍边距作为保守余量，随后仍使用原精确裁剪和索引规则。
共享模块只有开销改变，不改变参考风险类别、权重、桥梁许可或碰撞硬约束。
没有把视觉网格升级为已确认墙体或可通行地面。

## 许可到期归因

独立输入监控在释放记录中保存当时的控制阶段及在该阶段停留的时间。
阶段包括位置读取、方向读取、引导读取、导航、报告发布和采样等待。
更新阶段仅用于归因，不能续期许可、按下按键或阻止超时释放。
主线程返回后恢复阶段；不在后台监控线程中读取游戏内存或更新 UI。

阶段是触发释放时的上下文，不证明整段停键时间均由该阶段导致。
需关联建图耗时、读取耗时和真实输入间隔后再判断下一处瓶颈。

## 验证

新增测试先复现远处对象进入几何键计算、远处三角面进入高度裁剪两项问题。
其余测试覆盖原始快照不变、巨大跨区墙体、平面段、边界、扩大半径、
随机局部地图轮廓与连接判断等价、退化参考面的局部风险等价，以及阶段归因不续期。
已有桥梁、水域、岸侧引导、稳定锚点、独立输入保护及停止/失焦测试继续回归。

离线前后各独立建图 7 次，使用 4000 个远处合成碰撞体、200 个局部合成碰撞体、
同一份 6908 面参考数据，中位耗时约 140.9 ms → 51.1 ms；
两侧输出同为 200 个局部障碍轮廓和 1163 条参考风险条目。
测量时存在并行回归/打包负载，不是严格性能基准，更不代表实机跟随提速比例。

需在更新后人工回放核对实际建图耗时、局部保留对象数、许可到期阶段和松键间隔。
若输入仍因位置、方向、引导读取或报告阻塞到期，应按新日志处理对应阶段，
不得将剩余许可到期都归因于建图，也不得通过延长许可掩盖问题。

  另有 2 项子测试通过、26 条警告，用时 190.55 秒。
- 冻结包专项 525 项通过，103 个打包模块与候选代码一致；静态检查通过。

- 现有 25 个未提交/未跟踪文件的全部哈希保持不变。
- 实机行走效果及许可到期阶段分布，仍待更新后的人工回放验证。

# 每次寻路接入记忆库

日期：2026-11-04。基线：4b8b5d9。

## 保存与使用规则

每次回放继续保存路线快照、实际坐标、变化后的规划路径、受阻事件和结束状态，成功、失败、停止都保留。新增 `路线/寻路记忆库.sqlite3` 登记各次记录目录，并索引可复用的短程实走边。`learning.json` 指向该库，原日志格式及旧的每目标三条成功走法继续兼容。

规划线只作档案，不自动升级为成功走法。控制器需连续两次在同一输入、同一有效碰撞许可和同一场景几何作用域中读到有效坐标，且两点之间当前碰撞检查通过，才提交实际移动证据。松键、键组合变化、跳跃及其恢复窗口、场景变化、许可过期会中断连续性。原有载具/座位步行保护继续执行。修复普通点位记录器未拦截 `read_for_playback()`、可能绕过坐标归档的问题。

每条边保留起止 XYZ、方向（由端点确定）、移动方式、行走时长、来源和原始回放 ID。只表示“有步行输入且观测到连续位移”，没有可靠 grounded 或支撑面 ID，不能宣称已证实脚下地面。

同一采集点已有完整成功走法时优先使用；没有可用完整走法时，在附近已观测的有向边中寻找向当前目标推进的候选。接入、候选移动和之后的自主规划都继续检查实时碰撞和方向风险，不逆用边，不取消水域/山壁/墙体限制，不改变保存目标或到点采集条件。

短时卡住证据保留在原始事件中；位置新鲜且确认为步行阶段的 `movement_stall` 才用于附近同方向候选的临时降权。反向不受该方向降权。降权有效期为 120 秒，不生成永久硬墙。它不能保证下一次自主规划绝不会再次尝试该处。

## 身份、限额与故障

场景作用域使用当前 `cache_context` 和 `terrain_revision` 的散列，不保存原始 PID/地址字符串，不假造稳定世界身份。现有上下文包含进程/场景会话信息，因此本版只在同一可确认场景会话复用短程边；跨重启记录仍保留，但不会自动跨会话带路。旧完整走法仍按原实现重新核验。

工程过滤：相邻观测最长 1 秒、最大位移 3 单位、最大高度变化 0.35 单位；最近入口 4 单位。这些是保守的记录过滤参数，未经游戏能力实测，不能解释成角色最大坡度或台阶能力。

短程可复用索引至多 20000 条边，目录索引保留最近 2000 次；原始回放文件不因此删除。每秒至多一次批量写入，正常结束强制提交；异常崩溃可能损失未提交的最近一批索引，原始日志用于复盘。SQLite 使用事务、WAL、20 ms 锁等待；忙、损坏、版本不支持或无法写入时显示记忆索引警告，原始记录及按键释放流程继续运行。所有限额均为工程配置。

## 本次边界

本次只接入记录与候选复用，没有切换自动开地图设标的采集入口，也没有同时实现新的补采调度。单独跟随游戏引导会提供实走证据，但不会用记忆改写游戏引导目的地。历史旧回放不会被离线追认为成功步行；缺少输入/场景证据时仅保留档案。

离线测试不代表实机到达、实际采集或跨桥行为已经验证。部署后应先进行短距离回放，再核对原始档案、数据库边和实时碰撞下的候选复用。

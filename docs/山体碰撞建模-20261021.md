# 山体碰撞建模续作

日期：2026-10-21。本轮继续补全物理山壁模型、角色高度相关的碰撞投影和地图显示。它不是渲染地形复刻，也不是全图三维导航网格。

## 数据与公开依据

基于此前只读导出的 `mc_terrain_collider01` cooked PhysX 三角网格：6852 顶点、6867 面，来源面重映射唯一，范围小于原 6870 面，源物体变换为单位矩阵。原始导出 SHA-256：`8ce4bd25cbb960c8e4e14bdaebf294eda8dc8bfa58f3157d2be58845b75deb5a`。已有主地图和 GameAssembly 指纹门禁继续保留，其他地图或未知版本不加载这些固定参考。

本轮重新分析保存的网格，6778 面完全垂直、66 面倾斜陡峭、1 面中等斜坡、22 面接近平地，无退化面。66 个陡面坡角约 74.14～90 度，过去只提取完全垂直边，因而遗漏。原模型的 3398 段边界保留；额外陡面按原顶点及源面编号补入，未根据山体外观猜大包围盒。

通过用户指定的 `http://127.0.0.1:7897` 代理核对 GitHub 与公开资料，禁用环境代理继承，不回退直连：

- [Recast 官方三角面分类实现](https://github.com/recastnavigation/recastnavigation/blob/main/Recast/Source/Recast.cpp)：使用面法线与坡度阈值区分表面。这里仅借鉴几何分类方式，不引入 Recast，不照搬机器人或导航网格的参数。
- [Unity Mesh Collider 官方文档](https://docs.unity3d.com/6000.0/Documentation/Manual/class-MeshCollider.html)：碰撞依据网格及其烹饪后的几何；显示网格和实体包围盒不能替代实际三角面。

70 度筛选是本程序保守识别“近垂直墙面”的工程策略，**不是已测得的游戏最大爬坡角度**。平地和普通缓坡未转成墙。选中陡面作为双向保守障碍，不推断它的背面或上方一定可走。

## 改动

1. 新增 66 个真实倾斜陡面，共 3464 项山体碰撞参考。生成数据仅包含顶点和面编号，不含旧进程地址，不在运行时扫堆或调用游戏函数。
2. 倾斜面先按「脚底高度 + 原有地面间隙」至「脚底高度 + 原有身体高度」截取，再投影 XZ。避免将整个斜面轮廓沿高度方向无限挤出；水域和山壁终点不放松碰撞间隙。角色高度变化 0.2 单位后刷新切片，这是缓存更新策略，不是角色碰撞尺寸实测值。
3. 正常寻路、可见捷径和跳跃恢复共用切片检查，跳跃不能绕过已知山壁。三角面的高度信息也纳入几何缓存签名，不能因平面包围范围相同而复用旧面。
4. 地形由已验证的原生主场景身份决定，不再依赖可选的矿石/树木配置扫描；可选资源读取失败不会一并隐藏山体。真正世界切换或身份读取变化仍拒绝旧参考。
5. 已确认的固定山体随整个视野显示，保持与普通附近碰撞不同的筛选规则。模型自身有不可变缓存，不进入「走过才保留」的显示历史；缺失当前确认时不显示旧山体。缩放复用同一份索引与绘图缓存。

## 边界

当前补的是这份已核对碰撞网格中的陡面，不能据此宣称地形、山路、台阶、洞穴和所有其他 MeshCollider 已建模完整。未读取的动态碰撞仍受游戏加载范围约束。不同高度切片减少错层投影，但规划仍为局部高度近似的 XZ 寻路，缺少完整可走表面拓扑；长坡、跨层通路和高差目标仍可能需要补充实测。所有个人点位、缓存和回放记录保留。

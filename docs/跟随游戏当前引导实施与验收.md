# 跟随游戏当前引导：实施与验收

日期：2026-10-27。基线 `1857f10`。用户明确选择：手动 F6 开始，跟随当前游戏追踪路线，到路线末端附近停下，不自动交互。

## 使用流程

1. 在游戏中手动追踪目标，确保出现地面路线。先下车，关闭地图、背包等面板。
2. 打开本次新版，在“采集设定 → 回放控制”点击“跟随游戏引导 · F6开始 / F9停止”。无需创建或修改保存点位。
3. 切回游戏后按 F6。点击工具按钮本身不启动移动，读取器也在首次 F6 后才打开。
4. F6 暂停/继续，F9 停止。失焦、窗口尺寸变化、追踪目标或场景改变时，释放按键并暂停确认；追踪取消则停止。
5. 到游戏引导线末端附近后释放按键并结束，显示距实际追踪目标的水平距离，不按 F、不打开工具/背包，也不自动继续原采集回放。

结束消息明确是“到引导线末端”，不是“已精确到达交互位置”。本次只读观察到引导线末端与目标可以相距约 13.7 单位；不能把先前某次约 5～6 单位的间距设为游戏固定规则。本功能不擅自外推末段直线。

## 实现范围

- `utils/drivers/native_guidance.py`：通过构建指纹已校验的 `ReadOnlyPosition` 读取当前关卡模块，定位 `TrackingPathModule`。优先读取 `realPathList`，为空时读 `_path`，不调用游戏内部方法、不写游戏内存、不扫描整块堆。
- 模块归属、列表类型、元素类型/数量、版本、目标及启用标志在发布前复核；更新冲突返回失败，不拿旧路线继续输入。程序集/类型查找首次进行，之后复核缓存模块归属。
- `utils/core/guidance_path.py`：复制并校验有限坐标与新鲜度，移除连续重复点，沿路径的弧长游标前进；可以从人物所在的中途位置接入，不返回游戏保存的历史起点。局部搜索限制前后范围，不直接用终点替代折线。
- 原生路线 Y 仅作高度层提示；没有把整条路线统一减 0.5 当作真实地面。局部转向使用角色当前 Y，并继续由现有碰撞图处理水域、山壁、实体和桥梁约束。高度提示范围不是已测得的支撑面模型。
- `utils/flows/native_guidance_follow.py`：复用坐标有效性、只读方向和导航恢复逻辑；不执行走动方向校准。每轮读取或规划前释放输入，慢规划后重新确认源数据；恢复期间同样定期核对目标变化。
- 停滞按实际位移判断，临时转向点变更不能重置；同一障碍首次大跳、随后侧向绕行，连续失败和单点有效时间均有上限。无法继续就停止/暂停提示，不无限顶墙。
- `PointPlayback` 以独立任务占用输入门禁，记录实际轨迹、原生路径及异常；不建立走法记忆，不启动料理、维修、进食或采集控制器，不突出显示无关的保存点位。
- `tools/coordinate_monitor.py` 注入执行器，UI 不反向导入 flows。新按钮保留已有回放与停止入口。

本次没有把 1,745 节点的全局引导图自动接管所有采集寻路。用户在中途明确改为直接跟随当前目标，因此先前未完成的离线图测试单独封存至任务目录，未混入默认测试或提交。

## 2026-10-27：F6 已启动却原地等待的修复

### 实际故障与根因

用户回放日志显示：21:42:53 已接受 F6，随后成功读取追踪目标和原生引导线；21:42:55 起一直等待最新场景数据，实际轨迹文件为空。按钮、热键和路径读取均已执行，尚未进入移动输入阶段。

## 2026-10-27：完整引导路线缓存与独立恢复

### 本次授权与范围

用户选择“完整路线缓存优先，前方分段读取备选”，确认实施完整路线缓存＋局部跟随。本次不实现未经验证的局部分段内存读取降级：当前客户端能够提供完整引导列表；完整缓存无法验证时自动重试，不编造后续路线。

点击跟随后，后台线程先读取完整路径并显示“已缓存 N 个引导点”；F6 前允许只读准备，不发送任何移动或交互。F6 后重新确认目标/场景和状态时效，再从人物当前附近接入。旧的“首次 F6 前不打开读取器”测试按这次明确变更更新为“F6 前可读缓存，但绝不输入；停止时关闭已打开的读取器”。

### 真实发现：两种计时来源被混用

本机运行 Python 3.12.10。旧 NativeGuidanceReader 默认使用 time.monotonic，回放 PreciseClock.monotonic 实际返回 time.perf_counter。本次观察两者相差约 0.42～0.44 秒，而快照有效期为 0.5 秒；不能假定它们在当前环境共享可直接比较的起点。这会消耗大部分时效余量，加重间歇过期误报。

生产引导读取器改为 perf_counter，与回放统一。没有通过延长 MAX_AGE 掩盖时钟差异，也没有修改全项目其他模块的计时策略。没有将该偏移量硬编码为补偿值。

### 缓存与检查

- GuidanceRouteCache 存储当前任务唯一一份已校验完整路线，复制为不可变坐标元组；不写用户路线 JSON，不启用走法记忆。
- 路线内容的年龄不直接决定是否丢弃；运行健康状态继续有 0.5 秒时效要求。目标、场景、模块归属或路径变化时重新确认/更新。
- ReadOnlyPosition.guidance_status / NativeGuidanceReader.status 只读模块归属、启用标志、目标、两个集合的对象/尺寸/版本/数组引用，以及各列表首、中、末的采样坐标；读取前后复核一致性。
- 心跳令牌变化时先完整读取新路线，成功且能从当前附近接入后替换游标；完整读取失败时释放输入，不继续使用已经发现变化的旧路线。
- 心跳采样不能证明所有未采样坐标不变。每 2 秒执行完整 payload 复核，覆盖未增加版本号的原地修改；该检测存在至下一次全量复核的延迟，不宣称即时发现任意内存修改。
- 真实碰撞、河湖、山壁及桥梁约束继续由现有 LocalNavigator/场景安全门禁处理。缓存路径不等于已证明可行走地面。
- 慢规划后重新确认健康状态；路线未变时保留规划结果，不再仅因超过 0.1 秒刷新间隔而不断丢弃路线并重复规划。路线变化则放弃旧规划再计算。
- 暂停或恢复确认会清理任务缓存，重新确认目标后再接入；同一运行中暂时读取失败保留路径内容，释放按键并自动重试。

### 恢复、计时与诊断

GuidanceRecovery 分别跟踪 guidance、direction、scene 的连续等待；某项恢复只清理该项计时。完整准备成功清理整体等待。单项连续失败 15 秒或混合异常导致 30 秒无法完成一次准备后暂停，避免无限重试。F9、失焦、窗口尺寸变化、坐标突变保护继续有效。

新增集中阈值：AUDIT_SECONDS=2、RETRY_SECONDS=15、NO_READY_SECONDS=30，均为工程初值，不描述为游戏实测保证。旧 WAIT_SECONDS=3 保留兼容，本入口不再用它累加所有异类等待。

状态提示改为“状态暂未更新，正在重新读取”，不再把所有快照超时都描述成游戏目标已过期。日志新增等待阶段、连续等待时间、完整/心跳读取次数、最近读取/规划耗时与缓存点数。读取次数从进入跟随循环起统计，启动准备另有缓存就绪记录。

## 2026-10-27：竖直零厚度碰撞面与线段通行约束

### 根因与本轮边界

缓存版运行后仍发生持续“等待最新场景数据”。只读诊断保存了两片启用、非触发的 DynamicBoxCollider，Size=[1,2,0]；旧 box_geometry 仅允许 Size.Y=0 的平面，因此将这两片竖直面判为 Invalid scene box，导致 managed_unknown=2、托管碰撞 partial、导航门禁拒绝发布快照。等待不会修复持续存在的几何类型缺口。

本轮补齐恰有一个零尺寸轴、其他轴为正的平面，包括 X/Y/Z 三种轴向；不修改导航完整性门禁，不忽略未知几何，不调整路线缓存和恢复时限，不重新启用走法记忆。

### 实现

- scene_map.box_geometry 的 allow_planar 仍默认关闭，普通严格箱体 API 不变。允许平面时保留真实变换后的角点与高度；按实际世界法线判断竖直平面，投影保存为两端点，并标记 projection_kind=segment 和对应 surface_kind。
- 用 64 个单位量级浮点 ULP 处理竖直法线的计算舍入；这是无量纲数值容差，不是角色坡度、游戏厚度或人为填充的墙宽。具有真实倾斜的平面仍保留投影面积。
- 负尺寸、多零轴、非有限坐标或退化成单点的投影仍拒绝解析；不能把任意两点数组当作有效碰撞。
- 新增 collider_footprint，统一验证普通多边形与显式标记的平面线段。导航几何签名和 ObstacleMap 都使用该数据，不允许旧路径缓存忽略新线段。
- 线段沿用原有身体高度范围与角色间隙检查；不人工增厚原始几何。线段不参与采集终点的人工间隙缩减，已有起点向外退出间隙的规则保留。
- A* 邻接边、路径简化、前瞻与 WASD 量化脉冲继续复用同一个 clear 检查；没有重写寻路器，也不以画图结果代替碰撞结果。
- 桥梁检测继续要求有效面状几何，线段不能被当作桥面。真实水域、山壁、实体碰撞约束保持原有处理。
- SceneDisplayCache 的边界与场景失效逻辑支持已标记线段；这仍是显示缓存，不向导航提供历史碰撞。
- MapDrawCache 将线段用灰色线条绘制，普通轮廓、近处细节、围栏入口都避免使用退化的 Tk polygon；不绘制虚假的浅色墙顶，也不以图示宣称支撑面或实际可通行。

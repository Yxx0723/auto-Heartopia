# 只读方向优先与安全校准

日期：2026-10-24。在本地已完成的联合巡查及公共侧保护上增量修改；原有未提交成果保留。

## 实现行为

- 优先读取 LocalPlayerComponent._checker 所属 PlayerSphereChecker 的 _cameraForward，将其投影到 XZ 平面，转换按键方向。
- 同时核对角色及实体归属、字段类型、向量有效性、检测器位置与当前角色位置，以及读取前后的入口稳定性。连续两次方向一致才开始使用；并非把角色朝向当作镜头方向。
- 回放期间约每 0.1 秒核对；明显变化时释放移动键、重建局部导航状态。暂停后清除方向确认，重新读取，不直接沿用旧缓存。
- 正常行走继续产生方向证据；单次大角度偏移不再直接触发走动校准。只有一致的独立轴证据才将当前读数标记为冲突；靠墙侧滑不作为直接校准证明。稳定且几何检查通过的移动样本也用于更新行走速度估计。
- 身份不符、位置不同步、损坏或不可读的数据会等待重试，支持 F6/F9。不会因为方向读取失败就先跳跃。
- 已确认归属及同步，但镜头接近竖直而无法得到水平朝向，或正常行走持续证明读数存在冲突时，才可能使用备用试走；必须有新鲜导航数据，周围候选空地检查通过，并远离已知资源和家园约束。
- 备用试走单次按键为 0.15 秒；仍保留有限校准预算。旧的无方向接口离线适配器保留原流程，实际 ReadOnlyPosition 使用新的只读接口。
- 回放记录增加 direction_source，区分 memory、probe、unconfirmed、motion_conflict 等来源。没有重新启用走法记忆，也不修改用户采集点位和顺序。

## 修改位置

## 能力边界

- 只读采样确认的是当前类型、归属、数值及位置同步；没有在本轮真实控制角色验证 W/A/S/D 与镜头向量的映射。
- 两次一致不等于获得了游戏原生方向时间戳。正常移动证据继续用于检查读数，冲突时不会无限信任旧方向。
- 当前没有可靠 grounded 标志或完整地面网格。候选空地检查不等于真实坡度、台阶或支撑面能力验证；备用走动在这些场景仍需实机观察。
- 旧版本坐标适配器不支持类型化方向时保持兼容；不宣称所有历史坐标配置都能立即使用只读方向。
- 本轮不推送 GitHub。部署与已保存路线校验以 deployment-result.json 为准，没有自动启动回放或采集。

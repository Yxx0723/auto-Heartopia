# 载具附着坐标读取恢复记录

2026-10-26。基于 `69ebc08`，保留东海显示回退结果。

## 原因与实现

旧读取器在 `Hierarchy._parent` 非空时直接报“角色正附着于其他对象，暂停世界坐标读取”。本次只读诊断复现此错误，用户确认人物正在载具或座位上。

- 从历史提交 `139b8c0` 恢复载具附着读取，未恢复该提交的其他功能。
- 在现有层级数量上限内逐级检查类型、运行时归属、父级引用及根实体双向引用；根实体必须有效。
- 附着时使用已核对归属的无父级实体世界位置，保留 `attachment-root` 来源标记。它代表载具/座位根位置，与人物脚下位置有区别。
- 不合成中间 Socket 的位置：历史实现记录指出中间位置可能是世界缓存，直接相加会重复计算平移。
- 附着坐标的直接 CE 地址返回空值，避免把角色局部位置地址误导出为世界位置。
- 步行回放和房门巡查使用独立的 `read_for_playback()` 检查；附着时可以显示数据，但不能据此启动步行输入。巡查包装读取器继续调用发现回调。

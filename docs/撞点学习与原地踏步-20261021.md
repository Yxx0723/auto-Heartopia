# 撞点学习与原地踏步

日期：2026-10-21。回答「自动寻路还是会撞山」这一轮。结论：这一处不是山体陡面没建模，而是**那里根本没有可读的碰撞数据**，程序只能靠「撞过就记住」绕开。

## 现场证据

`outputs/回放记录/20261021-170815-905845-cc402fb5/`（12 点「矿石」路线，起点方式＝最近点接入，从点位 8 出发）与 `outputs/日志/点位回放.jsonl`：

| 时间 | 现象 |
| --- | --- |
| 17:08:26.8 → 27.3 | 从 (-84.4, 18.02, -134.8) 起连续 4 个采样坐标**完全相同**，键位按住但零位移 |
| 17:08:28.9 | 脱困开始：左右试走无位移；大跳把 y 抬到 19.62 |
| 17:08:32.4 → 33.4 | 跳上去后水平走约 0.6 单位，y 停在 19.62 |
| 17:08:35.9 → 36.4 | 重新校准，y 从 19.62 掉回 18.09，再掉到 17.82（约 1.5 单位高差） |
| 17:08:39.6 → 40.6 | 在 (-85.7, 18.10, -135.5) 又 4 个采样零位移，再跳到 19.37，再卡 |
| 17:08:44.6 | 用户 F9 停止 |

两次卡点的几何核对：

- 已建模山体参考（`terrain_walls()` 3464 项）在卡点 **6 单位内没有任何一项**，最近的一面在 15.1 单位外，高度 22.8～33.4，属于山体上部面。
- 用游戏进程只读导出一份实时场景（`MemorySceneMap`，未发送任何输入）：卡点 2.6 单位内只有 3 片细薄的 `verified-native-world-collider`，3.1 单位外才是那块山体参考；水域最近的 15.3 单位。
- 用同一份快照离线跑 `LocalNavigator.next_target` 到点位 8：**规划成功**，路径每 3 单位一点，`steering_keys` 返回 `{'w','a'}`。

也就是说：地图认为那里是空地，游戏认为过不去。缺的是两层东西：

1. 本程序只采集 `InstBoxColData` 方形盒与一份离线 `mc_terrain_collider01` 主城网格，**其他 MeshCollider 完全没有读**，那块地形属于没有读到的；
2. 模型是 XZ 平面加身体高度切片，**没有高度/台阶概念**；那份网格 6867 面里 22 面接近平地、1 面中等坡，都被「不是墙」排除，所以 1.5 米台坎在模型里不存在。y 在 17.3～19.6 反复 ±1.5，正是它在跟这道台坎较劲：跳上去，掉下来。

## 为什么原来会反复撞同一个点

`LocalNavigator.blocked()` 以前只在撞点前方 1 单位放一个半径 .45、20 秒过期的圆点，间隙只有 .3。规划器下一次从 .6 旁边就「合法」地绕过它，而那个「旁边」在游戏里照样走不通，于是同一个点反复撞、来回跳，直到连续失败到上限。

## 改动

`utils/core/coordinate_navigation.py`

- `blocked()` 改为调用 `_learn_block()`：沿**当时实际尝试的方向**在角色前方 1.2 单位放一道**横墙**（默认宽 2.4、厚 0.5），900 秒有效，覆盖一轮运行。
- 撞在同一处（3 单位内）不再重复放小点，而是把这道墙**加宽一级**（+1.2，最多 3 级＝7.2 宽）。真实障碍的宽度靠「撞一次加宽一级」逐次逼出来，不靠猜。
- 撞点记录 `blocked_points` 与世界上下文绑定：换世界清空，不与上一张地图的结论混用。
- 墙放在角色前方 1.2 单位，角色不在自己的间隙里；`ObstacleMap.clear(escape=True)` 仍允许向外走，所以不会把自己圈死。角色一旦站在墙的间隙内，该墙按既有规则被丢弃（防止自己困住自己）。
- `blocked()` 返回的现场证据新增 `learned_block`（等级、半宽、墙心坐标），随原来的 `obstruction` 一起进回放记录，便于按坐标补数据。

`utils/core/thresholds.py` 新增 `COORD_NAV_BLOCK_*` 八项并登记 golden；原 `COORD_NAV_PROBE_SECONDS` 随单个圆点一起删除。数值是按现有间隙（.3）与采样位移（约 .5）推出来的工程值，**不是实测碰撞尺寸**。

## 边界

- 这是「绕开」不是「看见」：它让角色不再重复撞同一处，但如果真实障碍比学到的墙更宽，会再撞一次并把墙加宽；连续 3 级仍过不去就按原有失败计数暂停或跳过该点。
- 没有补上缺失的 MeshCollider，也没有高度/台阶模型。长坡、跨层通路、台坎台阶仍需实机验证或后续补采集。
- 900 秒按一轮运行设计（单轮移动上限 600 秒），不做跨会话永久记忆；没有写进个人路线或走法记忆。

# 水域地图轮廓与缩放优化

## 数据核对

旧显示轮廓来自带房屋、车站等图标的截图。新版使用本地已保存的关闭房屋等标记的地图捕获，通过 SIFT 特征和 RANSAC 相似变换对齐到原内存校准坐标。281 对匹配中有 263 对内点；中位误差 0.166 像素，95% 误差 0.631 像素。变换主要是竖直平移 -6.754 像素，比例 0.999970，沿用原点 (511,452) 和 1.55 像素/游戏单位。

重新描出 56 块显示水域，补充西侧湖泊原先被车站标记覆盖的部分，调整多个河岸局部轮廓并过滤海岸边缘的新增噪点。净图仍有 NPC 图标和人物箭头，因此这些遮挡区域保留原参考；没有从遮挡内容推断水域。原有已记录干地小岛也保留。

新显示数据位于 `utils/core/water_display_reference.py`，旧 `map_water_reference.py`、`lake_areas.py` 和导航水域数据未替换。新显示轮廓不是实测碰撞面，不能据此声称所有水域已经识别，也不能据图标过滤后的截图推断全部桥梁可通行。

## 显示与缓存

岸边使用较浅水色，水面内部使用较深水色，细描边突出河岸。这是显示样式，不表示水深。小岛和桥梁层位于水面上方。

水域外轮廓预先生成三档精度：1422、721、539 个顶点。比例小于 0.85 像素/单位使用远景档，0.85～2 使用中景档，2 以上使用细节档。远景外轮廓顶点较细节档减少约 62%；这不是 FPS 提升的测量值。内部着色轮廓同样分档。

运行时不扫描截图、不重做轮廓提取，也不动态简化曲线。每档 Canvas 图元和视口筛选结果缓存复用，切回同一档不会反复创建相同图元；关闭水域显示时各水域子层一起隐藏。没有使用可能让河岸越过原边界的贝塞尔平滑。

## 核对范围

新增回归覆盖被图标遮挡的湖泊、旧裁切区两侧的河段、已知干地和小岛、三档缩放、缓存复用和隐藏。桥梁与北侧河道寻路回归同时运行。输出的前后对比图使用相同坐标和比例，只呈现水域层，便于检查轮廓。

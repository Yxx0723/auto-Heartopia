# 侧栏紧凑化（一屏放下）

完成时间：2026-10-22T17:02+08:00。前置：`窗口配色统一为林地绿-20261022.md`。

## 问题

右侧栏常用状态下内容约584px，默认窗口视口641px，顶部还可能出现留白；一旦顶部出现通知条（连接错误、清空失败等）就超出，得滚动才能看到「采集」和「内存地图」。底部的判断行（`低于20%自动维修`、`体力低于30`）也各自独占一行，留白多、信息密度低。

## 改法

`utils/ui/monitor_layout.py`

- 通知槽空态不再占位：建好后立即 `notice_bar.grid_remove()`，只有真的有文案才出现（`render_notice` 里有 `self.notice_bar.grid() if text else self.notice_bar.grid_remove()`，所以错误条该出现时仍会出现）。
- 侧栏滚动区 `scrollregion` 改为 `(0, 0, width, max(视口高, 内容高))`，并把内容比视口矮时的 `yview_moveto(0)` 归位——避免通知显隐后残留负的 canvas 原点，出现「最上面空一条」。
- 间距收紧：分区之间的 `rule` 从 6px 降到 4px，多处 `SPACE['sp2']`(8) 降到 `SPACE['sp1']`(4)。
- 「连按 F × 次」从独占一行挪到「采集」标题同一行右侧（`row 8, column 1..2`）。
- XYZ 三格读数高度 58 → 46。
- 工具卡：提示文案 `wraplength` 260 → 120，`低于20%自动维修` 复选框从第 3 行整行挪到第 2 行右侧，与提示并排。

`utils/ui/monitor_painter.py` / `utils/ui/hud_kit.py` 只跟着 1–3 行适配（通知态复用、读数内边距）。

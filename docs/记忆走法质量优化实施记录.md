# 记忆走法质量优化

日期：2026-11-05。基线：6e27018。用户确认三类问题同时处理，并允许在当前有效碰撞检查下尝试更短路线，走通才计成功，保留原始回放和旧候选。

## 已核对问题

带有效计时剖面的 remember() 原先跳过回环清理；相似新走法被旧形状归并时，可能保留旧绕行几何却把新耗时记在旧形状上。采集导航选中完整记忆后立即返回，缺少直接通行候选的比较。历史前瞻的横向偏差仅 0.15，细小摆动也会迫使控制器逐点修正；已越过的采样点仍可能成为回头目标。

只读检查到苹果路线有同一目标 63.43 与 26.60 单位等不同长度候选，但这些候选起点也不完全相同，不能仅据总长度判定哪条在当前位置更快。

## 修改行为

带计时和不带计时的新增路径均清理精确 XYZ 回返；旧记录只在 lookup 的执行视图清理，不离线改写文件。仅拼接完全相同的已观测节点，附近但不相同的点不能据此拉直。清理后的计时仍包含原来真实花掉的行走时间，不把省下的路程伪装成已经实测的时间。后续真正更快的一次回放才能更新实际耗时。

相似的新走法明显缩短且耗时没有明显变差时，可以成为新的独立形状候选；旧候选仍按原来的三条上限策略保留。一个不同形状的耗时不再直接记到旧形状上。没有可靠旧计时的记录不以乐观估算阻止实际走通的新短形状。

在碰撞快照完整有效时，采集记忆前瞻的抖动包络使用 0.35，并检查真实碰撞和方向风险。已沿下一段越过的点不再要求折回精确命中；真正弯道、高度差和障碍检查继续参与。缺少完整有效快照时继续采用原有保守前瞻。

旧走法比当前直线至少多 1 单位且至少绕远 20% 时，每秒最多检查一次直达试走候选。只有当前整段处于局部地图覆盖、有效托管和原生碰撞快照、同一近似高度、无实体/水域阻挡、无方向风险时才尝试。当前实现优先处理明确直达却绕远的情况，不执行额外全图搜索来竞争每条复杂绕行。

试走期间每个控制周期继续复核碰撞与范围，不强制松键去做无变化比较。选择试走不会改写成功记忆，实际到达且完成原有点位流程后才学习。试走受阻会暂时禁止同目标同场景的直达试走，回退旧走法或局部规划，不把失败归罪于尚未使用的旧候选。

## 边界与验证

上述距离、收益比例、检查间隔和抖动包络属于工程参数，并非游戏实测能力。不同高度层不试直线，没有补出 grounded 或完整地面网格。未知空间仍可能在实际尝试中失败；原有进展预算、有限脱困、补采、F9、失焦和独立按键许可继续约束。

保留原始回放目录、保存点位和其他未提交工作。本次不批量清空记忆库，也不离线把所有近似回环改成直线。离线测试覆盖精确回环与计时、相似形状更替、旧文件执行视图、近似回环保留、前瞻抖动、越点进展、墙体约束、失效快照、不同高度和失败试走回退。实际行走自然程度及新走法耗时仍需部署后的相同路段验证。

# auto-Heartopia

auto-Heartopia 是《心动小镇》的 Windows 桌面辅助工具。你可以在独立窗口查看角色位置和附近资源，保存并回放自己的采集路线，跟随游戏引导，或在灶台旁自动制作料理。

## 功能介绍

| 功能 | 可以做什么 |
| --- | --- |
| 实时坐标与地图 | 查看角色当前位置和移动轨迹，缩放附近地图或查看整条路线。 |
| 资源显示与分类 | 按类别查看已识别的果灌、树木、岩石、矿石和动物。资源标记表示位置，实际能否采集以游戏为准。 |
| 自动采集与路线管理 | 记录自己的采集点，保存多条命名路线，按顺序回放，在到达点位后尝试采集。 |
| 智能寻路与避障 | 回放时尝试绕开已识别的障碍和水域。复杂路段可以手动通过，或在可通行处补充点位。 |
| 游戏引导跟随 | 游戏里有可识别的引导方向时，可启动「跟随游戏引导」。 |
| 体力与工具辅助 | 查看体力和工具耐久。采集回放中可在条件满足时补充体力、拿出斧镐或使用维修盒。 |
| 自动烹饪与连续制作 | 在灶台旁制作所选料理。程序按实际提示翻锅，完成后收菜并核对背包成品。 |
| 实时运行日志 | 在窗口底部查看烹饪进度、已确认的成品数量和任务停止原因。 |

## 获取与启动

1. 使用 Windows 10 或 Windows 11。本仓库目前没有公开的 EXE 下载，已获得发布版 EXE 的用户可以直接运行。
2. 通过游戏官方入口启动《心动小镇》，进入角色可操作的场景。
3. 打开工具的 EXE。如果 Windows 提示需要管理员权限，请按提示授权。若工具提示无法读取游戏，可右键 EXE，选择「以管理员身份运行」。
4. 等待工具自动连接游戏。窗口显示角色位置后，即可使用地图和任务功能。

## 使用教程

### 自动采集

1. 新建或选择一条命名路线。在游戏中走到要采集的位置，在工具中点击「添加点位」。按希望回放的顺序记录各点，复杂转弯处可补充点位。
2. 添加的点位会自动保存到当前路线。路线保存在程序旁的 `点位` 文件夹，仓库不提供预设采集路线。
3. 设置循环次数和采集等待时间，点击「▶ 回放」。
4. 切回游戏，按 **F6** 开始。需要暂停时按 **F6**，结束任务按 **F9**。

### 地图功能

1. 连接游戏后查看角色位置和附近轨迹，用鼠标滚轮调整视野。
2. 在地图上方选择资源分类，可以同时查看多个类别。
3. 点击「路线全览」查看整条已保存路线。开启相应图层可查看附近已识别的障碍和参考水域。

### 自动烹饪

1. 打开「烹饪」页，选择游戏中已解锁的料理，点击「刷新背包材料」确认可用材料。
2. 设置「连续锅数」，范围为 **1～99**。设为 **1** 只做一锅。设为更大的数量时，连续制作同一种料理。
3. 在游戏中手动走到可操作的灶台旁，确认灶台空闲，并处理当前弹窗。
4. 在工具里点击「开始」，切回游戏按 **F6**。保持游戏在前台，通过窗口底部日志查看进度。
5. 程序确认收菜后同一灶台恢复空闲、指定成品库存增加，才会计入一锅并准备下一锅。材料不足、读数异常或操作结果无法确认时，批次会停止，已确认的锅数会保留。

## 快捷键

| 快捷键 | 用途 |
| --- | --- |
| **F6** | 开始已准备的任务。路线回放可用它暂停或继续。 |
| **F9** | 停止当前任务。 |

烹饪时的 **ALT 和鼠标点击**（翻锅）以及**主键区数字 `1`**（收菜）由程序执行。任务运行期间请等待程序处理提示。

## 常见问题

### 为什么显示游戏未连接？

确认游戏已进入角色场景。切换场景后等待工具重新连接。如果工具提示读取权限不足，请按提示以管理员身份运行。

### 为什么自动采集暂停？

切出游戏会暂停回放。工具、体力或位置无法确认时，也可能暂停或停止。查看窗口中的提示，处理后按当前任务状态操作。

### 为什么角色无法绕过障碍？

工具只使用已识别的障碍和参考水域。复杂地形或跨楼层通路可能无法规划，可停止回放并手动通过，或在可通行处补充点位。

### 为什么烹饪任务自动停止？

材料不足、游戏失焦、界面或灶台状态无法确认时，程序可能停止。查看底部日志中最后一条失败记录。若灶台上还有旧锅，请先查看并处理当前锅次，再开始新任务。

### 烹饪记录保存在哪里？

新记录保存在当前 Windows 用户的 `%LOCALAPPDATA%\auto-Heartopia\烹饪记录` 中。若无法取得有效的 `LOCALAPPDATA` 路径，使用当前用户目录下的 `AppData\Local\auto-Heartopia\烹饪记录`。旧桌面记录保留在原处。验证灶台入口时会检查新旧目录中的待确认记录，无法核对时会提示停止。

### 为什么没有成功制作下一锅？

先检查目标锅数。连续制作中，上一锅必须确认收菜、灶台空闲且指定成品库存增加，随后还要重新核对食谱和材料。任何一步无法确认，批次都会停止。

### 为什么游戏更新后部分功能失效？

更新可能改变游戏界面、数据或交互方式。工具无法确认当前状态时，可能拒绝连接或停止相关功能，请关注仓库后续更新。

## 使用须知

- 当前仅支持 Windows。采集回放、引导跟随和烹饪等操作需要游戏位于前台。
- 地图和寻路无法覆盖所有地形。自动烹饪也有尚未充分验证的场景，首次使用可从单锅开始。
- 游戏更新可能影响功能。出现异常时，程序可能安全停止，必要时可按 **F9**。
- 使用前请自行了解并遵守游戏规则。

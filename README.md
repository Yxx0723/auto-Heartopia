# auto-Heartopia

《心动小镇》Windows 原生坐标观测与路线回放工具。实时读取本地角色 XYZ，手动添加采集点，按保存顺序行走、按 F 采集并等待。使用独立窗口，无需浏览器。

## 功能

- 实时 XYZ、XZ 移动轨迹与游戏连接状态，轨迹图始终以角色当前位置居中并自动跟随；界面隐藏内存地址等技术信息。
- 可将实走 XZ 轨迹导出为分段 JSON，用于补录静态游戏数据未覆盖的道路支路。
- 内存地图在轨迹图上显示已加载的场景物体、有效实体碰撞轮廓和参考湖泊水域；蓝莓使用蓝色带圆果标记、树莓使用粉红色带菱形果标记、普通灌木使用绿色丛状标记，其他物体使用灰色小圆点；可分别开关图层并刷新。
- 蝴蝶、其他昆虫、鸟类和小动物分别使用双翅、虫形、飞鸟与爪印图标，随场景数据约每 2 秒刷新。
- 已识别的树木使用绿色树冠和棕色树干图标，可通过“树木”分类单独显示，并复用地图绘制缓存。
- 已核对的可采集岩石、矿石分别使用灰色岩块和带晶体的矿块图标，支持独立分类、多选与悬停距离；识别依赖实际采集组件和资源编号，普通装饰石块不按外形猜测为矿点。固定矿点与其他已确认地物共用显示缓存。
- 主地图完整石矿资源定义自动读取并缓存，覆盖角色附近尚未加载的区域；点击分类面板中的“岩石 / 矿石全览”查看全图。附近实时资源优先并去重，远处点位注明“全图资源位置”，只表示资源位置，不表示当前可采集状态；切换场景后校验并移除旧世界数据。
- 地图上方分类按钮支持单类查看及多选：首次点击只看该类，继续点击可增加或取消类别；“全部分类”恢复全部显示，“清空显示”仅隐藏物体标记，当前位置及保存点位始终保留。
- 地图默认显示固定比例的附近视野，远处路线不会挤小局部细节；支持滚轮缩放、“路线全览”和可还原的“大地图”布局。
- 固定地图元素自动缓存，缩放和移动视野时复用已绘制的物体、碰撞轮廓与湖泊；连续滚轮操作合并刷新，动物位置仍随新场景数据更新。
- 地图采用分层配色、湖岸描边、树冠高光、编号点位与角色方向指示，带比例尺和图例；可叠加已核对的外环及三条支路参考，保留缺口，仅用于显示。
- 点位编号自动避让，重叠点合并显示编号，保留各点真实位置与采集顺序；鼠标悬停可查看点位、物体分类与平面距离，缓存物体带参考提示。当前回放目标高亮，目标在视野外时显示方向与直线距离，青色寻路线路显示在点位顺序连线之上。
- 点位回放默认启用局部自动寻路：结合最新盒形碰撞轮廓和参考水域规划绕行，青色虚线显示当前路径；远距离分段规划，仅在保存点位按 F 采集。暂未找到路径时留在当前目标重试，仍支持原来的大跳脱困、最近点接入及循环。
- 自动寻路支持窄通道细网格搜索和最多 60 单位半径的扩大绕行，复用未变化的障碍地图，减少重复规划及短路段切换时的按键抖动；脱困试走和大跳也避开已知水域。
- 路线走法记忆默认开启：成功完成的路段保存实际行走轨迹，下次从附近接入并复用；保留拐角，逐段复核新障碍，不通时重新寻路。支持查看段数和清除当前路线记忆，重开程序后仍保留。
- 贴近树干的保存点支持最后一段谨慎接近；越过中间路点后继续向前，镜头方向改变时复核并重新校准，到点停稳后采集。回放状态与中断原因保存在 EXE 旁的 `日志/点位回放.jsonl`，自动限量轮换。
- 显示当前手持工具的名称与耐久，回放时自动拿出斧镐；低于 20% 时可使用普通维修盒，等待效果并核对耐久恢复后继续。
- 显示角色实际体力，低于 30 点时可通过背包优先食用普通水果，核对体力增加、关闭背包后继续原点位；工具及食物识别支持不同分辨率。
- 添加当前点位，多条命名路线，新建、另存为、改名、删除和清空当前路线点位。
- 按点位顺序回放，支持完整路线或最近点接入、1～999 轮循环。
- 到点短按 F，支持默认等待及逐点等待时间；暂停保留当前轮次、点位与剩余等待。
- 每次遇阻先长按空格大跳，再后退和左右绕行；每轮脱困次数可选，默认 5 次；次数用完或达到距离边界后自动继续重试。
- F6 开始／暂停／继续，F9 停止；切出游戏自动暂停，异常退出释放按键。
- 只读游戏内存，不写入坐标、不注入代码。

仓库不提供预设采集路线。自己的路线保存在程序旁的 `点位/` 目录，走法记忆保存在其中的 `路线记忆/` 子目录，均已从 Git 跟踪范围排除。

## 从源码运行

环境：Windows 10/11、64 位 Python 3.12。游戏由用户通过官方入口手动启动，进入角色后程序自动连接。读取游戏进程可能需要以管理员身份运行终端。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe tools/coordinate_monitor.py
```

创建环境并安装依赖后，也可运行 `Start-Heartopia.bat`。

## 打包 EXE

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm packaging/HeartopiaMonitor.spec
```

生成 `dist/HeartopiaMonitor.exe`，为单文件原生窗口程序，包含管理员权限清单。构建配置使用仓库相对路径，可在其他电脑复现；不包含游戏文件、个人路线或旧的固定地址表。

## 使用与限制

1. 进入游戏，在需要采集的位置点击“添加当前点位”，按行走顺序添加；转弯处补充点位。
2. 设置路线、起点方式、循环次数、采集等待和每轮脱困次数。
3. 点击“按顺序回放”，切回游戏按 F6。初始校准需要空旷平地；回放期间保持镜头稳定。

内存地图每约 2 秒只读刷新，默认显示范围为 150 游戏单位，附近 80 单位使用最新场景数据，远处固定地物可显示已读取的缓存；范围可选 80～400 单位，不会修改游戏的实际加载距离。地图显示已确认的有效实心盒形碰撞体在 XZ 平面的投影，蓝色河道与湖泊采用经坐标校准的近似参考轮廓，右侧可单独关闭“河道与湖泊”。自动寻路使用最新场景快照中的实心盒形碰撞体和参考水域，显示开关及历史绘图缓存不影响规划；快照过期或未找到路径时释放按键并重试。地图尚未覆盖全部地形、球形或引擎内建碰撞体、导航网格，因此不能将它当作完整通行地图。参考水域可能误挡桥梁，复杂坡面与跨楼层通路尚未可靠识别。大范围障碍和复杂拐角仍可补充点位，或关闭自动寻路后手动引导。F 后的等待是定时等待，尚未识别游戏中的采集完成状态。

道路参考图目前只覆盖从游戏路线定义筛出的主干道、部分支路和局部步行候选，不能保证覆盖完整岛屿道路。补录时先在轨迹图点“清空轨迹”，在游戏里沿一段缺失支路走完，再点“导出实走路段”；JSON 默认保存在程序旁的 `道路数据/实走轨迹/`。导出会保留坐标断点，不会把分开的移动段连起来。把文件交给维护者后，可叠加到道路预览并逐段核对。

坐标定位按游戏模块指纹和运行时对象元数据校验。游戏更新、换场景或坐标失效可能需要更新配置；版本不匹配时会拒绝读取。游戏内完整路线与复杂障碍通过效果仍需实测。

详细操作见 [使用说明](docs/使用说明.md)，避障设计依据见 [障碍处理与参考资料](docs/障碍处理与参考资料.md)。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests personal_tests -q
```

2026-10-20 的完整隔离回归为 **1900 passed、27 xfailed、2 subtests passed**，包含仓库分层约束、图像识别、地图缓存、路线记忆、自动寻路、脱困及自动补给。27 项 xfail 是保留的已知缺陷，不表示全部功能已经实机验证。回放、跳跃和按键释放测试使用替身，不操作真实游戏；原生窗口布局与实际游戏内存读取另行只读检查。

同一段 120 单位直路的模拟对比中，启用路线记忆时，地图构建从 245 次降至 27 次，路径规划从 239 次降至 53 次，按键按下与松开事件从 504 次降至 26 次。目标到达精度与仅在采集点按 F 的行为保持不变。这些计数来自模拟场景，不能视为实际游戏帧率或通行成功率的保证。

路线记忆会在每段成功到达并完成采集后持续更新，保存实际通行轨迹、有效行走耗时和成功次数；采集等待不计入行走耗时。相同点位保留至多三条成功走法，优先选择预计剩余耗时较少的路径，未计时的旧记录按路程估算。遇到新障碍会降低原走法优先级并学习成功绕行；原有路线记忆继续兼容，不改变采集点和顺序。只学习真实走通的路径，不把未经验证的跨河直线当作捷径。

主地图现已显示山体、岩壁等地形阻挡边界（棕色轮廓），来自当前版本真实地形碰撞网格的3398条竖直边界。普通寻路与脱困均避开这些边界，采集点附近也不会放松山壁限制；正常坡道不按整山包围盒封锁。边界只在匹配游戏版本和主地图场景时启用，缓存绘制，不在运行时反复扫描内存。地图右侧“山体与碰撞”只控制显示，隐藏后仍会参与避障。

自动补充体力改为背包搜索：体力数值低于30时，按苹果、蓝莓、树莓、橘子的顺序搜索普通水果；名称相同的食谱不会作为水果选用。确认选中水果和食用按钮后才食用，体力实际上升后退出搜索结果并关闭背包，再继续当前点位。文字输入使用Unicode，不依赖中文输入法或改写剪贴板；暂停、失焦、停止仍会释放按键。已恢复体力但关闭失败时只处理背包收尾，不重复吃水果。
